# aiviz

This project is a small streamlit app which runs an LLM and vizualizes llm insights for outputted tokens.

View this app on streamlit cloud:

<https://aiviz-dashboard.streamlit.app/>


## Prerequisites

- Python 3.14+
- uv package manager
- make

## Development Commands

List all makefile commands
```sh
make
```

Run local development server:

```sh
make dev
```

Run lint checks:

```sh
make lint
```
